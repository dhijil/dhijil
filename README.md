### 3. Acoustic Keystroke Recognition & Active Audio Masking *(Local Project — Pending GitHub Upload)*
`Python` · `Flask` · `Scikit-learn` · `Librosa` · `HTML / CSS / JavaScript`

A full-stack machine learning and audio-security web application for classifying keyboard keystrokes from `.wav` audio and studying active acoustic defense.
- Built a feature-extraction pipeline in **Librosa** (85 acoustic features: MFCC mean/std, ZCR, RMS, spectral centroid, bandwidth, and rolloff) across **42 keyboard classes**.
- Trained a tuned Linear **SVM** classifier achieving **98.32% test accuracy** (**98.14%** 5-fold cross-validation accuracy) on the `593`-sample dataset, served via a **Flask** `/predict` API to a web UI.
